# SENTINEL — Security Command Center

חמ״ל אישי למצלמות Xiaomi שלך: שידור חי של **Xiaomi Smart Camera C200** ו-**Xiaomi Outdoor Camera CW300** זה לצד זה, מהמחשב, ברשת הביתית בלבד.

החיבור למצלמות נעשה דרך **[go2rtc](https://github.com/AlexxIT/go2rtc)** ומקור ה-Xiaomi המתועד שלו (`xiaomi://`, זמין מגרסה v1.9.13). לא מניחים RTSP או ONVIF, ולא עוקפים את האימות של Xiaomi.

---

## הפעלה מהירה

דרישות: **Node.js 20 ומעלה**. בשביל מצב ההדגמה בלבד צריך גם **ffmpeg** (לא נדרש למצלמות עצמן).

```bash
cd sentinel
npm run setup      # התקנת חבילות + הורדת go2rtc v1.9.15 הרשמי + build
npm start          # מפעיל את go2rtc ואת לוח הבקרה
```

אחר כך פותחים בדפדפן: **http://127.0.0.1:8080**

### חיבור המצלמות (פעם אחת בלבד)

הכול נעשה מתוך **הגדרות ← חיבור מצלמות Xiaomi** בלוח הבקרה:

1. **התחברות ל-Xiaomi בממשק הרשמי של go2rtc.** לוחצים על "פתח את go2rtc" ועל "הצג פרטי כניסה ל-go2rtc" (או מריצים `npm run credentials` בטרמינל). הדפדפן יבקש את שם המשתמש והסיסמה של go2rtc.
   ב-go2rtc בוחרים **Add ← Xiaomi**, בוחרים את ה-**Region** של החשבון (כמו שהוא מוגדר באפליקציית Xiaomi Home), מזינים את פרטי Xiaomi ולוחצים Login. אם נשלח קוד אימות או מופיע captcha, משלימים אותו שם.
   SENTINEL לא רואה את סיסמת Xiaomi שלך בשום שלב. go2rtc שומר רק טוקן, בקובץ `data/go2rtc.yaml` שמוחרג מ-Git.
2. **איתור המצלמות.** חוזרים ל-SENTINEL ולוחצים "חפש מצלמות" (אפשר להשאיר "כל האזורים"). יופיעו המצלמות מהחשבון עם **מזהה הדגם האמיתי** שמגיע מ-Xiaomi.
3. **הוספה.** נותנים לכל מצלמה שם, בוחרים פנימית או חיצונית ולוחצים "הוסף".
4. **בדיקת חיבור אמיתית.** ברשימת המצלמות לוחצים "בדיקת חיבור", או מריצים בטרמינל:
   ```bash
   npm run verify          # HD לכל מצלמה
   npm run verify -- --sd  # גם SD
   ```
   הבדיקה מושכת 6 שניות של וידאו אמיתי דרך go2rtc ומדווחת מה התקבל בפועל: קודק, רזולוציה, מספר פריימים ונפח. **אם לא התקבל וידאו, הבדיקה נכשלת.** אף מסך לא מציג "LIVE" בלי פריימים אמיתיים.

### הפעלה אוטומטית אחרי הדלקת המחשב

```bash
npm run autostart:install   # Windows: Task Scheduler · macOS: LaunchAgent · Linux: systemd --user
npm run autostart:remove
```

SENTINEL יעלה בכל כניסה למשתמש, יפעיל את go2rtc ויפעיל אותו מחדש אם הוא נופל. הלוג נכתב ל-`data/sentinel.log`.

## תאימות המצלמות: מה ידוע ומה לא

נבדק מול קוד המקור של go2rtc v1.9.15 ורשימת המצלמות הרשמית ([issue #1982](https://github.com/AlexxIT/go2rtc/issues/1982)):

| מצלמה | מזהה דגם | מצב ב-go2rtc |
|---|---|---|
| Xiaomi Smart Camera C200 (2023) | `chuangmi.camera.046c04` | **נתמכת ומאומתת.** מופיעה ברשימה עם פרוטוקול cs2+tcp, וידאו HEVC/H.265 ואודיו Opus, 1920×1080 / 640×360. בקוד יש לה גם הגדרת איכות ייעודית. |
| Xiaomi Outdoor Camera CW300 | לא מתועד | **לא מאומתת.** הדגם לא מופיע ברשימה (מופיעות CW100, CW400, CW500, CW700S ו-AW300). לפי go2rtc, רוב המצלמות שיוצרו אחרי 2020 עובדות, אבל רק בדיקה אמיתית תכריע. |

- **לא ניחשתי את מזהה הדגם של ה-CW300.** SENTINEL קורא אותו מהחשבון שלך בשלב האיתור ומציג אם הדגם מאומת.
- אם יש לך C200 מגרסה אחרת (מזהה שונה מ-`chuangmi.camera.046c04`), היא תסומן כלא מאומתת, ושוב הבדיקה האמיתית תכריע.
- **אם ה-CW300 לא עובדת:** הריצו `npm run verify` והעתיקו את הודעת השגיאה (היא מסוננת ולא כוללת מפתחות). לפי ההנחיות של go2rtc, מצלמה שלא עובדת מדווחים ב-issue חדש בפרויקט שלהם. אם היא כן עובדת, אפשר לדווח עליה ב-#1982.

### מגבלות ידועות (מהתיעוד של go2rtc)

- **בכל חיבור למצלמה צריך גישה לאינטרנט**, כדי לקבל מפתחות הצפנה מענן Xiaomi. הווידאו עצמו עובר **ישירות ברשת המקומית** (P2P מקומי).
- המחשב והמצלמות צריכים להיות באותה רשת ביתית.
- **H.265/HEVC:** ה-C200 משדרת HEVC. דפדפנים שמנגנים את זה: Chrome או Edge מגרסה 136 ומעלה, ו-Safari. **Firefox לא מנגן HEVC.** אם רואים "מתחבר..." לנצח בלי שגיאה, נסו Chrome או Edge מעודכנים. אם עדיין לא עובד, עברו ל-SD.
- איכות: go2rtc תומך ב-`subtype=hd/sd`. SENTINEL יוצר לכל מצלמה שני זרמים, HD ו-SD, ומאפשר להחליף ביניהם בפקדי התצוגה.
- דווח על באג בגרסה v1.9.14 במק עם שבב Apple ([#2048](https://github.com/AlexxIT/go2rtc/issues/2048)). SENTINEL מתקין v1.9.15. אם במק יש `i/o timeout`, אפשר לנסות גרסה אחרת: `GO2RTC_VERSION=v1.9.13 npm run install:go2rtc -- --force`.

## מה יש בממשק

- **לוח בקרה:** שעון ותאריך חיים, מונה מצלמות שמשדרות באמת, חיווי מצב מערכת ושתי תצוגות וידאו גדולות.
- **בכל תצוגה:** שם ומיקום, חיווי **LIVE** רק כשפריימים באמת מגיעים לדפדפן, חיווי **OFFLINE** או התחברות מחדש, מסך מלא, הפעלה והשתקה של אודיו (הכפתור פעיל רק כשבשידור יש ערוץ אודיו), החלפה בין HD ל-SD, צילום תמונה (JPEG מהפריים החי) וחיבור מחדש ידני.
- **התחברות מחדש אוטומטית:** אם לא מגיעים פריימים במשך 10 שניות, הנגן פותח חיבור חדש. אם go2rtc קורס, SENTINEL מפעיל אותו מחדש.
- **מצלמות חיות:** תצוגה מורחבת, מצלמה אחת או שתיים בשורה.
- **הגדרות:** אשף החיבור, שמות, סדר, הסתרה, בדיקת חיבור, איכות ברירת מחדל ומצב הדגמה. הכול נשמר ב-`data/settings.json`.
- **עברית ו-RTL מלאים, מצב כהה, רספונסיבי:** במחשב יש תפריט צד, בטלפון יש סרגל ניווט תחתון.
- **מצב הדגמה:** שתי תבניות בדיקה סינתטיות של ffmpeg עם הכיתוב **"DEMO · NOT A CAMERA"**. הן לא נספרות כמצלמות מחוברות.
- **הקלטות ואירועים:** שלב 2. העמודים מסבירים מה חסר. **לא מוצגים נתונים מומצאים.** ל-go2rtc אין ערוץ אירועי תנועה של Xiaomi, ולכן לא הוספתי התראות. גם שליטה בתנועת מצלמה (PTZ) לא מומשה: ל-C200 יש סיבוב באפליקציה של Xiaomi, אבל מקור ה-Xiaomi של go2rtc לא חושף פקודות תנועה, ולכן אין דרך מתועדת ומוכחת לממש את זה כרגע.

## אבטחה

| נושא | איך זה מטופל |
|---|---|
| חשיפה לרשת | ברירת המחדל היא `127.0.0.1` בלבד, כלומר רק המחשב הזה. אין פתיחת פורטים בראוטר ואין UPnP. |
| go2rtc | מאזין רק על `127.0.0.1:1984` עם סיסמה שנוצרת אוטומטית, ו-`local_auth: true` דורש אותה גם מהמחשב עצמו. CORS כבוי. |
| הדפדפן | לא מקבל אף פעם את הסיסמה של go2rtc. SENTINEL מתווך את ה-WebSocket ומתיר רק שמות זרמים שהוגדרו. |
| מקורות | אפשר להוסיף רק כתובות `xiaomi://` במבנה המדויק ש-go2rtc מחזיר, כך שלא ניתן לנצל את הממשק כדי להריץ `exec:` או מקורות אחרים. |
| שרתים מיותרים | RTSP, RTMP ו-SRTP של go2rtc כבויים. RTSP כבוי בכוונה, כי go2rtc לא דורש סיסמה מחיבורי localhost. |
| WebRTC | במצב מקומי הוא כבוי, והווידאו עובר ב-MSE דרך ה-WebSocket המאובטח, בלי פורט נוסף. במצב LAN נפתח פורט 8555 ברשת הביתית (נדרש לאייפון). אין שרתי STUN ציבוריים. |
| סודות | טוקן Xiaomi, הסיסמה של go2rtc ומפתח העוגיות נשמרים ב-`data/` עם הרשאות לבעלים בלבד (700/600). התיקייה מוחרגת מ-Git. |
| לוגים | מפתחות, טוקנים (`V1:...`), `client_private`, `sign` וכתובות Xiaomi מסוננים לפני כל הדפסה. |
| דפדפן | בדיקת Host header (הגנה מפני DNS rebinding), בדיקת Origin לבקשות משנות ול-WebSocket, CSP מחמיר וגופנים שמוגשים מקומית בלי בקשות חיצוניות. |
| כניסה | במצב LAN חובה `SENTINEL_PASSWORD` (לפחות 10 תווים), אחרת השרת מסרב לעלות. העוגייה היא HttpOnly ו-SameSite=Strict, ויש חסימה אחרי 5 ניסיונות כושלים. |

### צפייה מהטלפון ברשת הביתית

ב-`sentinel/.env` (מעתיקים מ-`.env.example`):

```ini
SENTINEL_HOST=0.0.0.0
SENTINEL_PASSWORD=סיסמה-ארוכה-משלך
```

מפעילים מחדש ונכנסים מהטלפון ל-`http://<כתובת-ה-IP-של-המחשב>:8080`. במצב הזה WebRTC נפתח על פורט 8555 (TCP+UDP) ברשת המקומית. ב-Windows תופיע בקשת אישור של חומת האש: **אשרו רק "רשתות פרטיות"**.

> ⚠️ החיבור ברשת הביתית הוא HTTP ולא מוצפן. **אל תפתחו פורט בראוטר.** לגישה מחוץ לבית, הדרך המומלצת לשלב 2 היא VPN פרטי (למשל Tailscale או WireGuard), לא חשיפה לאינטרנט.

## ארכיטקטורה

```
 דפדפן (React)  ──HTTP/WebSocket──▶  SENTINEL server (Fastify, 127.0.0.1:8080)
   go2rtc player (video-rtc.js)        ├─ settings / setup / status API
   MSE  (או WebRTC במצב LAN)           ├─ WebSocket bridge ─▶ go2rtc /api/ws  (רשימת זרמים מותרים)
                                       └─ מפעיל ומשגיח על go2rtc (child process)
                                                   │
                                         go2rtc (127.0.0.1:1984, סיסמה)
                                                   │ xiaomi:// — מפתחות מענן Xiaomi, וידאו P2P מקומי
                                         C200  ·  CW300   (ברשת הביתית)
```

```
sentinel/
├─ server/src/
│  ├─ go2rtc/       manager (הפעלה, השגחה, סינון לוגים) · client (API)
│  ├─ cameras/      models (תאימות) · service (מצב) · probe (בדיקת וידאו אמיתית)
│  ├─ settings/     store (JSON מקומי, zod, כתיבה אטומית)
│  ├─ security/     auth (Host/Origin/login) · secrets · redact
│  └─ routes/       api · stream (WebSocket bridge)
├─ web/src/         React + TS + Tailwind + Lucide (RTL)
│  ├─ components/   CameraTile, TopBar, Sidebar, ...
│  ├─ vendor/       video-rtc.js — הנגן הרשמי של go2rtc v1.9.15 (MIT), ללא שינוי
│  └─ lib/          sentinel-video.ts (התאמות: בלי STUN, reconnect מהיר, אירועי שגיאה)
├─ scripts/         install-go2rtc · verify-cameras · autostart · credentials · dev
├─ tests/           e2e-demo.cjs (Playwright, מצב הדגמה)
├─ bin/             go2rtc (מורד, מוחרג מ-Git)
└─ data/            go2rtc.yaml, secrets.json, settings.json (מוחרג מ-Git)
```

## פתרון בעיות

| תסמין | מה לעשות |
|---|---|
| `go2rtc binary not found` | `npm run install:go2rtc` |
| אין חשבון Xiaomi אחרי ההתחברות | לרענן את ההגדרות. לוודא שההתחברות ב-go2rtc הסתיימה בלי שגיאה ושנבחר ה-Region הנכון. |
| "לא נמצאו מצלמות" | לנסות "כל האזורים". המצלמות צריכות להיות משויכות לאותו חשבון באפליקציה. |
| "מתחבר…" בלי סוף | 1) Chrome או Edge מגרסה 136 ומעלה (HEVC). 2) לעבור ל-SD. 3) `npm run verify` להודעת שגיאה מדויקת. 4) לוודא שהמחשב והמצלמה באותה רשת ושיש אינטרנט. |
| `i/o timeout` | חיבור P2P מקומי נכשל: בידוד לקוחות (AP isolation) ברשת האורחים, VLAN נפרד או חומת אש. כדאי לחבר את המחשב לאותה רשת Wi-Fi או LAN של המצלמות. |
| אין כפתור אודיו פעיל | אין ערוץ אודיו בשידור שהתקבל, או שהאודיו כבוי באפליקציית Xiaomi. |
